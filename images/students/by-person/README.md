# 学生照片放置说明

每位学生对应一个独立文件夹。把该学生的一张 JPG、JPEG、PNG 或 WebP 照片放进对应目录即可，文件名可以任意。请每个目录只放一张正式照片；`.gitkeep` 是用于保留空目录的占位文件，不用删除。

照片放好后告诉我“照片已放好”，我会按文件夹对应成员更新中英文页面配置并推送。
